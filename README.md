# UWA Student Grade Analyzer

## Description
This project analyzes student marks using Python and Pandas. It calculates average marks, assigns grades, ranks students, and generates reports.

## Features
- Calculate average marks
- Assign grades (N, P, CR, D, HD)
- Pass/Fail analysis
- Student ranking
- Subject averages
- Export reports to CSV
- Data visualization using Matplotlib

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Project Files
- UWA_Student_Grade_Analyzer.ipynb
- student_grade_report.csv
